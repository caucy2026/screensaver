# 1.0.3 KEMI屏保品牌与短循环

应用名称统一为 KEMI屏保，54 种语言资源保持相同品牌名。新原创图标由深色圆角底、银蓝双屏和光带组成，提供自适应与普通矢量版本。

所有视频循环限制在 12 秒以内，构建中强制检查。A 从原第 32 套已增强视频选择自然速度的单镜头，用 9 帧叠化形成 63 帧 / 2.1 秒短循环；C 保持 305 帧 / 10.167 秒。原壁纸工程的 set32 未变。

A 已完整解码且没有音轨、黑帧区间，封面取自新成片；C 沿用 1.0.2 验证结果。63 已连接，原双屏旋转均为 free/default。当前未签名草稿未安装；签名授权及缺 B 时是否允许 A/C 测试待确认。
